# دفتري

موقع ملاحظات بالعربي، فيه إنشاء حساب وتسجيل دخول بالإيميل.

- **الحسابات والبيانات:** Firebase Authentication و Cloud Firestore (مشروع `zoof-2fcde`)
- **الاستضافة:** Netlify
- **قواعد الحماية:** `firestore.rules`، وتُنشر يدويًا من Firestore ← Rules

موقع ثابت بدون خطوة بناء: `index.html` و `app.js` و `styles.css` و `firebase-config.js`.
